# yomates-threads-skill

요메이트(Yomates)에서 내 스레드(Threads) 계정에 글을 올리고, 답글을 달고, 조회수와 댓글을 확인하게 해 주는 스킬과 CLI예요.

## 쓰는 법

1. 이 저장소의 [SKILL.md](SKILL.md)를 요메이트 팀원에게 주고 이렇게 말해요.
   > 이 파일 읽고 'threads-연결' 스킬로 저장해 줘. 그다음 그대로 연결해 줘.
2. 직접 하실 일은 페이스북과 스레드에 로그인하는 것뿐이에요. CLI 설치, Meta 개발자 앱 만들기, 권한, 테스터 등록, 토큰 연결은 요메이트 팀원이 브라우저에서 해요.
3. 연결이 끝나면 "스레드에 이 글 올려 줘", "오늘 달린 댓글 보여 줘"처럼 말로 쓰면 돼요.

## 들어 있는 것

- `threads.mjs`: Node.js 18 이상만 있으면 도는 스레드 CLI예요. 외부 패키지를 하나도 쓰지 않아요.
- `SKILL.md`: 요메이트 팀원이 읽는 설치·사용 안내예요.

## 보안

- 토큰은 맥이면 키체인, 윈도우면 내 계정만 풀 수 있는 암호화 파일, 리눅스면 내 계정만 읽는 파일에 저장돼요.
- 토큰은 복사 버튼으로 클립보드에 담고, CLI가 한 번 읽어 저장한 뒤 바로 클립보드를 비워요. 채팅이나 AI 화면에 나오지 않아요.
- 클립보드 기록 앱(Paste, Raycast, Win+V 등)을 쓰시면, 연결 뒤 기록에서 그 항목을 지워 주세요.
- Meta 앱은 각자 만들어요. 앱 검수 없이, 테스터로 등록한 본인 계정에만 올려요.
